# Detail Questions

## Q6: Should the Vision Pro app automatically connect a human helper when Gemini's confidence score drops below a threshold (e.g., <70%), or should users manually request helper connection?
**Default if unknown:** Yes, automatic connection (safety-first approach for accessibility - users may not realize AI is uncertain)

## Q7: When multiple objects are detected simultaneously, should spatial audio play overlapping descriptions at once from each object's location, or queue them sequentially based on what the user is gazing at?
**Default if unknown:** No, queue sequentially based on gaze (overlapping audio would be confusing and overwhelming)

## Q8: Should visual annotations (bounding boxes, labels) for detected objects persist in 3D space as the user moves around, or only appear when actively looking at objects?
**Default if unknown:** No, only appear when looking (persistent annotations would clutter the view and reduce accessibility)

## Q9: For critical safety information (allergens, warnings, expiration dates), should the system interrupt other audio descriptions immediately and use a distinct alert sound?
**Default if unknown:** Yes, immediate interruption with alert sound (safety information is time-critical)

## Q10: Should the mobile companion app continue streaming video to Vision Pro even when the phone screen is locked or app is backgrounded?
**Default if unknown:** Yes, background streaming required (users need hands-free operation, phone should stay in pocket)
