# Initial Request

**Date:** 2025-10-03 22:51

## Project Overview
Context-Aware Object Reader for Apple Vision Pro - "Be My Eyes" style accessibility application

## Full Description
There are currently no dedicated accessibility applications for Apple Vision Pros. We want to create a "Cluely" style Context-Aware Object Reader for Daily Life for HackHarvard's Human Augmentation Track.

### Core Concept
Point at anything - medication bottles, street signs, ingredient lists, control panels - and get instant audio descriptions with spatial awareness. Unlike phone apps, it's hands-free and knows exactly what you're looking at based on head/eye gaze.

### Key Features
- **AI Processing:** Using Gemini for AI processing
- **Fallback Support:** Information stream to mobile livestream for helpers to see when AI processing fails
- **Smart Alerts:** Expiration date alerts, allergen warnings that pop up automatically
- **Agnostic Design:** General pre-prompt to highlight all important information (agnostic to specific use cases)
- **Multi-modal Output:** Text/visual and audio outputs
- **Mobile Companion:** Data stream from a mobile companion app

### Vision
This will be the future for remote support, combining AI-first processing with human backup when needed.

### Track
Human Augmentation Track - Push the boundaries of human ability through accessibility tools and AR/VR experiences
