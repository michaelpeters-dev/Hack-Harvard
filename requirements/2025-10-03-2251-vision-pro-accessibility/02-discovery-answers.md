# Discovery Answers

**Answered:** 2025-10-03 22:51

## Q1: Will the Vision Pro app need to work completely standalone without requiring the mobile companion app at all times?
**Answer:** No - the Vision Pro will be getting data 24/7 from the livestreamed mobile companion app

## Q2: Should the system store user interaction history and preferences locally on the Vision Pro?
**Answer:** No - this feature is not needed at this time

## Q3: Will users need real-time video streaming to human helpers, or is it acceptable to have a slight delay (2-5 seconds)?
**Answer:** Real-time required - dangerous things could occur if there's even a slight delay

## Q4: Should the app support multiple languages for audio descriptions and text output?
**Answer:** No - English-first for hackathon MVP

## Q5: Will the Vision Pro app need to handle multiple simultaneous object detections in a single view, or focus on one object at a time based on gaze?
**Answer:** Yes - multiple objects needed (e.g., being able to differentiate between apple and orange simultaneously)
